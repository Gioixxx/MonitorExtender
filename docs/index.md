# MonitorExtender

Trasforma un tablet Android nello schermo di un PC Windows, via cavo USB o via Wi-Fi.
Dal tablet puoi anche comandare il mouse del PC.

> **Duplica lo schermo, non lo aggiunge.** Il tablet mostra lo stesso desktop del PC: non
> diventa un secondo monitor indipendente.

## Scarica

**[⬇ Scarica per Windows](https://github.com/Gioixxx/MonitorExtender/releases/latest)** —
installer, nessun prerequisito.

L'app Android si scarica dalla stessa pagina di release finché non è sul Play Store.

## Come funziona

Il PC cattura lo schermo, lo ridimensiona, lo codifica in JPEG e lo trasmette al tablet via
Wi-Fi o cavo USB. Nessun account, nessun server esterno: PC e tablet si parlano direttamente
sulla stessa rete locale.
